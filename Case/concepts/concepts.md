## 변경: LCD 가로 배치
LCD 모듈 50(X)×35.5(Z)×8, 창 35.6×32.3 (모듈 중심 기준). 외곽 W×H×D 옛값 → 새값:
- A: 115×102×77 → 128×102×77 (W +13)
- B: 77×155×82 → 77×140.5×82 (H -14.5, 앞면 스택이 높이 결정, 보드 블록은 여유)
- C: 176.5×86×54 → 176.5×88×54 (H +2: 엔코더 body와 배터리 사이 3mm 확보)
플렉스: A 우측(+X)으로 나와 우벽 3mm 틈에서 뒤(+Y)로 꺾음 / B 좌측(-X) 10mm 후 뒤(+Y) 10mm / C 우측(+X) 20mm 그대로(꺾임 없음).

## 충돌 해결 (LCD 가로 이전 기록)
(아래 중 플렉스·C 엔코더 이동 항목은 위 변경으로 대체됨: C 엔코더는 이제 LCD 바로 아래 중앙)
- LCD 플렉스(20mm): A는 보드와 부딪쳐 뒤쪽(+Y)으로 꺾음. B는 엔코더 body와 부딪쳐 뒤로 꺾음. C는 아래로 두고 엔코더를 LCD 중심에서 +28mm 옆으로 이동.
- A 스위치: 보드 위, 후면 벽에 붙여 배치 (보드 윗면 z 27 위, 스피커 챔버 y 43 뒤). 보드 최고 부품과의 간섭은 확인 필요.
- B 배터리(y 46~58)는 엔코더 body(y 0~30)와 충돌 없음 (z 0~90 그대로). 스위치는 배터리 위(z 112~119)에 둠.
- C 배터리: 스피커 뒤 배치는 90mm가 보드 영역과 겹쳐 불가. LCD와 보드 사이에 눕혀 z 28~80에 놓음(엔코더 z 0~27 위).
- C 깊이 41(내부)로 줄이려면 엔코더 body를 23mm 이하로 줄이거나 엔코더를 폭 방향 밖으로 빼야 함.

## 변경: C 엔코더 위치 (옛 C 삭제 -> C1, C2)
옛 C는 엔코더 노브가 정면 맨 아래(책상 높이)라 돌리기 불편해 두 안으로 나눔. 공통: 벽 3, 간격 3, 높이 Hi=71 = Pi+HAT 세운 블록 70 + 0.5x2 (스피커 66은 가운데). 개구부(USB-C 우측, 스위치 우측, 이어폰 상단)·LCD 플렉스(우측 2.5mm 후 뒤로 꺾임) 유지.
- **C1 (엔코더 정면 옆)**: 정면 왼쪽부터 스피커(x0-66) / LCD(69-119) / 엔코더(body x124.5-150.5, 중심 x137.5, LCD와 같은 높이). 폭은 보드 블록(x69-170.5)이 결정해 176.5 유지(LCD+엔코더가 앞에 들어감). 외곽 **176.5 x 77 x 69**. 노브 중심 높이 = 책상 위 **38.5mm** (벽 3 + 35.5). 엔코더 body(y0-30) 때문에 보드는 y33-48, 배터리(90x52x12, 12는 Y방향으로 세워 x57.5-147.5, z9.5-61.5)는 보드 뒤 y51-63 -> 엔코더와 충돌 없음, 깊이 63(옛 C보다 +15). 배터리가 앞 줄에 안 들어가는 이유: 엔코더/LCD/스피커 뒤 빈 공간이 90 폭이 안 나옴.
- **C2 (엔코더 상단)**: 엔코더 body(z41-71)가 LCD(z2.5-38) 위, y1-27에 위치(노브 위로 +25), LCD와 3mm 간격. 보드 y30-45, 배터리 y48-60(보드 뒤). 외곽 **176.5 x 77 x 66**. LCD가 낮게(창 중심 높이 23) 위치하는 것이 단점.
- 옛 C 스위치 위치(x150.5-170.5, y12-25, z12-19)는 엔코더 원통 우측 끝(x150.5)과 z 간격 3.5로 유지.

## 추가: A2 (A 보다 얇게, 보드 세움)
A와 같은 정면(스피커 왼쪽, 가로 LCD 오른쪽, 엔코더 상단 LCD 뒤, 챔버16). Pi+HAT 블록이 뒷벽에 세워짐(X101 x Z70 x Y15, Pi 왼쪽/HAT 오른쪽). 그래서 USB-C와 전원 스위치는 우측 벽, 이어폰 잭은 상단.
- 배터리 (b'): 90x52x12를 바닥에 눕히고(z0-12) 그 위에 스피커와 보드를 올림(바닥 +15). 외곽 **128 x 91.5 x 67.5** (A: 128x102x77 -> 높이 -10.5, 깊이 -9.5).
- 배터리 (a) 좌측 벽에 세움(12 x 52 x 90): 외곽 약 143 x 96 x 67.5 (폭 +15, 높이 90 때문에 H 96) -> 체적 더 큼, 탈락.
- 배터리 (b) 엄격안(보드 바닥, 배터리를 보드 앞에 눕힘): 배터리 Y 52 + 3 + 보드 15 -> 깊이 약 76.5로 이득 없음. (b')는 배터리를 보드 아래까지 확장해 해결.

## 추가: A3 (A2 변경, 사용자 승인안)
- 챔버 깊이 16 -> 12 (스피커 합계 27+12 = 39). 챔버 바로 뒤에 2mm 칸막이(별도 파트 "챔버 칸막이", 스피커 X/Z 범위 그대로), 1mm 간격, 보드 블록 15(뒷벽에 밀착). 깊이 3+39+2+1+15+3 = **63** (A2 67.5 -> -4.5). 외곽 **128 x 91.5 x 63**.
- 보드 블록 좌우 반전: HAT 왼쪽(스피커 뒤, x0.5-64), Pi 오른쪽(LCD 뒤, x71.5-101.5). Pi Wi-Fi 안테나가 스피커 자석에서 멀어짐 (Pi 위에 안내 라벨). HAT 먼 변이 왼쪽을 향해 USB-C·전원 스위치는 좌측 벽, 이어폰 잭은 상단(HAT 위, x28-36, 엔코더와 떨어짐).
- 충돌/해결: (1) 전원 스위치는 A2 위치(앞쪽 우측 빈 곳)가 반전 후 스피커/칸막이 뒤로 막혀, 배터리를 x26-116 으로 우측 이동시키고 스위치를 좌측 바닥(x0.5-20.5, z2-9, 부싱 z5.5)에 둠. (2) 엔코더 body(y11-37, z55.5-85.5) 와 보드 블록(y42~) 간격 5mm, Pi(x71.5-101.5)와 겹치는 X 범위지만 Y로 분리돼 충돌 없음. (3) LCD 플렉스(y4-23.2, 우측 벽 쪽 x120.7-121.5)는 Pi(y42~, x<=101.5)와 간섭 없음.
- 파트 쌍별 AABB 충돌 검사 통과(케이스 내부 이탈 없음).
- 전원 스위치 위치 변경: 좌측 바닥(z2-9, 너무 낮음) → 우측 벽 뒤쪽, Pi 바로 옆. 몸체 x102-122(-X 방향), y41.5-54.5, z54.5-61.5, 부싱 중심 y48·z58(책상 기준 높이 61 = 전체 91.5의 2/3), 바깥 6 돌출. Pi(x<=101.5)와 간격 0.5, 엔코더(y<=37)와 4.5, LCD 플렉스(y<=23.2)와 18 이상, 뒷벽(y57)과 2.5. USB-C는 좌측 유지.

## 변경: A3 보드 뒤집기(②) 반영 (검토 P1-② 채택)
외곽 W×H×D 옛값 → 새값: **128×91.5×63 → 128×91.5×70.6** (D +7.6, 내부 122×57×85.5 → 122×64.6×85.5, 595 → 674 cm³).
- 깊이 합: 3(앞벽) + 27(스피커) + 12(챔버) + 2(컵 뒷벽) + 2(간격) + 3(자른 납땜 리드) + 1.6(PCB) + 17(부품+꽂은 케이블) + 3(뒷벽) = **70.6**. (내부 y: 컵 뒷벽 39-41, 리드 43-46, PCB 46-47.6, 공간 47.6-64.6)
- 보드 블록: 부품면이 뒷벽을 향함. 스피커 쪽 면엔 리드만. "커넥터·케이블 공간 17" 반투명 상자, 스탠드오프 9개(Ø5.5, 길이 17, 뒷벽→PCB; HAT 5 + Pi 4, 홀 위치 근사).
- 스피커 챔버: 칸막이 → 밀폐 5면 컵(벽 2: 뒤/위/아래/오른쪽, 왼쪽은 케이스 벽). 컵 X0-68, Z13-83. LCD(x69)와 1, 배터리(z12)와 1, 엔코더(x81~)와 분리, 위 벽까지 2.5.
- Pi: SD 끝이 위. 위 벽 SD 카드 슬롯 14×3 (x79.5-93.5, y47.8-50.8).
- 전원 스위치: z54.5-61.5 → **z66-73**(부싱 중심 z69.5 = 책상 위 약 72.5), y41.5-54.5 → 49.1-62.1(부싱 y55.6). Pi와 X 0.5, 엔코더(y<=37)·LCD 플렉스(y<=23.2)·뒷벽(y64.6, 2.5)과 분리.

- 배터리 커넥터: 보드 아래 변, 정면 기준 x8-20(뒤에서 보면 오른쪽), 플러그가 z3-15 빈 바닥으로 향함(x26부터 배터리와 분리). 상자 12×9×12.
