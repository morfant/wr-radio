# v08 HAT 배선 진행 기록

배선 방식: Claude가 KiCad Python(pcbnew) 스크립트로 구역별로 그리고, 구역마다 확대 그림을 사용자에게 보여 확인받은 뒤 다음 구역으로 간다. 그린 선·비아·존은 잠가서 나중 자동 배선(Freerouting)이 건드리지 못하게 한다.

- 스크립트는 KiCad GUI가 **닫힌 상태**에서만 돌린다 (`pgrep -fl kicad` 확인).
- 구역 스크립트는 재실행 가능하다: 자기 구역의 선·비아·존을 지우고 다시 그린다.
- 그림 도구: `tools/v08board/dump_region.py`, `plot_region.py` (구역 메모는 `notes_<n>_<이름>.json`).
- 자동 배선 도구: Freerouting 2.5.0 `~/Applications/freerouting/freerouting-2.5.0.jar`, Java는 `$(brew --prefix openjdk)/bin/java`.

6. **소프트웨어(시제품 후)**: HP_DET은 재생 중에만 믿기(S1, DAC 꺼지면 잘못 "꽂힘"으로 읽힐 수 있음), battery.py 충전 표시, GPIO25 충전 상한, charging_test.py ×3 버그, Pi 시리얼 콘솔 켜기. 초록 LED가 너무 밝으면 R5 → 2k.

다른 기계에서 이어 할 때: 브랜치 `pcb-v08-kicad`를 받고, KiCad 10 설치. 스크립트는 KiCad GUI를 닫고 KiCad 내장 python으로만 실행. 다시 배선할 일이 없으면 Freerouting은 필요 없음.

### 빈 Pi 핀 (확장용, 2026-11-12)
보드에 확장 패드는 (J10 하나 말고는) 넣지 않기로 함. **7번(GPIO4)은 이제 버튼 패드 J10이 씀(구역 11, 2026-11-12).** 나중에 엔코더·버튼을 더 달 때는 손납땜하는 J1 헤더 핀에 전선을 직접 붙인다. 남은 빈 핀(물리 핀 번호 → BCM): ~~7 → GPIO4~~(J10), 21 → GPIO9, 24 → GPIO8, 26 → GPIO7, 29 → GPIO5, 36 → GPIO16, 38 → GPIO20. (27/28 = GPIO0/1은 HAT ID EEPROM용이라 피함.) GND: 6, 9, 14, 20, 25, 30, 34, 39. 풀업은 Pi 내부 풀업 사용. 아이디어: 기기별 스트리밍 지연 조절 — 우선 소프트웨어(시스템 메뉴 "Delay" 항목 + 기존 엔코더, 또는 웹 관리 화면)로.
