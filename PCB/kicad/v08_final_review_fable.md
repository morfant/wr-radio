# v08 HAT 주문 전 최종 검토 (Fable, 2026-11-12)

대상: `PCB/kicad/radio-hat-v08/` (커밋 `073b6d9` 상태의 `.kicad_pcb` / `.kicad_sch` / BOM). 보드는 읽기만 했고 프로젝트 파일은 고치지 않았다. 좌표는 KiCad mm.

검사 방법: `kicad-cli sch erc`, `kicad-cli pcb drc --schematic-parity --severity-all`(원본 + 사본에서 `--refill-zones`), 회로도 넷리스트를 뽑아 부품별 핀↔넷 표로 대조, pcbnew로 풋프린트·패드·선폭·존·Fab 외곽 덤프, 구역 그림(전원/배터리/LED/J4 주변), v07 Eagle 보드와 J1 핀 위치 대조, 세션에 남아 있던 데이터시트(XL-1606SURC C965860, PJ-307C C16684) 도면 직접 판독.

## 결론: 수정 필요 (2건 처리 뒤 주문 가능)

회로(핀 배치·값·GPIO 매핑)와 전원 경로, DRC 상태는 문서에 적힌 대로이고 문제를 찾지 못했다. 다만 아래 2건은 주문 전에 처리해야 한다.

1. **M1** 측면 LED D2/D3의 극성이 아직 확정되지 않았다. 이전 검토는 "1번 핀 = 캐소드"라는 번호만 맞췄고, 렌즈 방향 기준으로 캐소드가 어느 쪽인지는 데이터시트 안에서 그림끼리 서로 반대다.
2. **M2** C25(22 µF, 높이 1.25 mm)가 전원 스위치 커넥터 J4의 플러그 공간 안에 있다. 사양서 5절의 "부품 없는 플러그 공간" 규칙을 어긴다.

둘 다 잘못되어도 보드가 타거나 Pi가 망가지는 종류는 아니다(LED가 안 켜짐 / 스위치 플러그가 끝까지 안 들어감).

## 반드시 고칠 것 (MUST)

### M1. D2/D3 XL-1606 극성: 데이터시트 그림 두 개가 서로 반대 — 번호가 아니라 방향으로 확정해야 함

- 보드 현재 상태 (pcbnew 덤프):
  - D2 (62.63, −36.95) r−90, D3 (62.63, −32.95) r−90, 풋프린트 `LED_XINGLIGHT_XL-1606_Horizontal`.
  - 풋프린트 기준: 렌즈가 −Y(화면 위)일 때 패드 1(K)이 **왼쪽**(−0.815, 0).
  - 보드에서는 렌즈가 +x(보드 가장자리)를 보고, 패드 1이 위쪽 (62.63, −37.765) = `/CHRG_N`, 패드 2가 아래쪽 (62.63, −36.135) = `/LED_CHRG_A`. D3도 같은 구성.
- 데이터시트 C965860 (XL-1606SURC) 7쪽:
  - 치수도 3개 모두 ②(+)가 왼쪽, ①(−)이 오른쪽. 캐소드 표시(초록 띠)는 ① 쪽.
  - "Recommended Soldering Pattern"(PCB를 위에서 본 그림)에 부품 외곽이 겹쳐 그려져 있는데, **렌즈가 위일 때 초록 표시가 오른쪽 패드 쪽**이다. → 렌즈 위 기준 캐소드 = **오른쪽**. 이대로면 현재 풋프린트(캐소드 왼쪽)는 **반대**다.
- 같은 데이터시트 8쪽(테이프 그림):
  - 포켓 안 부품은 렌즈가 오른쪽, 그리고 "스프로킷 구멍 쪽이 음극"(다이오드 기호도 캐소드가 구멍 쪽).
  - 이를 렌즈가 위가 되게 돌리면 캐소드 = **왼쪽**. 이대로면 현재 풋프린트가 **맞다**.
- 즉 두 그림이 거울상이다. 이 부품은 앞뒤(두께 0.6 방향)가 대칭이라 어느 면이 위로 테이핑되어 있느냐에 따라 극성이 뒤집히는데, 데이터시트만으로는 정할 수 없다. 이전 검토의 "두 LED 모두 1번 = 캐소드" 확인은 D2와 D3가 **서로 같다**는 것만 보장하고, 풋프린트와 맞는지는 보장하지 않는다.
- 틀렸을 때: 두 LED 모두 안 켜진다. 역전압 약 5 V가 1 k를 거쳐 걸리지만 전류가 제한되어 손상 가능성은 낮다. 충전 자체는 정상. 측면 LED라 180° 회전으로는 못 고친다(렌즈가 안쪽을 봄).
- 할 일 (하나를 골라 확정):
  1. **JLC/EasyEDA의 C965860 풋프린트를 열어** 렌즈(부품 외곽의 돌출부) 방향 기준으로 패드 1이 어느 쪽인지 본다. JLC 조립은 자기 라이브러리 풋프린트의 방향을 기준으로 놓으므로 이것이 가장 직접적인 근거다. (이번 검토에서는 EasyEDA API 접근이 막혀 직접 못 봤다.) 현재 풋프린트와 반대면 로컬 풋프린트의 패드 번호 1↔2를 바꾸고(Fab 모따기·실크 표시도 반대로), `/CHRG_N`·`/LED_CHRG_A`, `/STDBY_N`·`/LED_STDBY_A` 끝 토막 4개를 다시 잇는다(R4.2 (60.7, −36.15), R5.2 → y −32.1 선, 상태선 y −37.4 / −34.2 — 모두 1~2 mm 토막).
  2. 확정이 안 되면 주문 메모에 "D2/D3: side-view LED, lens must face the board edge (+X); cathode = pad 1 (upper pad). If lens direction and polarity conflict, please contact me before placing"를 적고, JLC 조립 미리보기에서 렌즈 방향을 확인한다.
  3. 그래도 반대로 왔을 때의 대비책: 이 LED는 앞뒤 대칭이고 전극이 양 끝을 감싸므로, **떼어서 뒤집어(위아래 면을 바꿔) 다시 붙이면** 렌즈는 그대로 바깥을 보면서 극성만 바뀐다. 손납땜으로 고칠 수 있다.

### M2. C25가 J4(전원 스위치) 플러그 공간 안에 있음

- 근거 (pcbnew 덤프):
  - J4 (27.7, −34.41) r180, 핀이 −x 방향. Fab 외곽 x 17.61~28.07, y −40.81~−33.09. 플라스틱 앞면 x 23.66.
  - 사양서 5절: "플라스틱 앞면에서 J1 쪽으로 15 mm(x 8.66~23.66, y −41.3~+2.8)는 부품 없는 플러그 공간".
  - C25 (11.25, −40.3) r180, 0805 22 µF(CL21A226MAQNNNE, 높이 1.25 mm). 패드 범위 x 9.80~12.70, y −41.02~−39.58 → 이 공간 안이다. 보드에서 플러그 공간을 침범하는 부품은 이것 하나뿐이다(J5/J6/J7 공간과 헤더 핀 아래는 비어 있음을 확인).
  - 3핀 듀폰 하우징(폭 7.62, 길이 14)은 y −40.76~−33.14, x 9.66~23.66을 차지한다. C25 몸체(x 10.25~12.25, y −40.93~−39.68)와 y 방향으로 약 1.1 mm, x 방향으로 2 mm 겹친다. 3번 핀(GND, y −39.49) 자리다.
  - 라이트앵글 헤더 핀 중심 높이는 약 1.3~1.5 mm, 하우징 두께 2.54 mm → 하우징 밑면은 보드에서 0~0.25 mm. C25(1.25 mm)에 약 1 mm 걸린다.
- 결과: 표준 듀폰 하우징이 끝까지 안 들어가거나 들린 채 꽂힌다. 전원 스위치 연결이라 접촉 불량이면 전원이 꺼진다.
- 고칠 방법: C25를 플러그 공간 밖으로 옮긴다. 조건은 몸체가 **y ≤ −41.0** 이거나 x ≤ 9.5. `/HP_DET` 넷 위 어디든 되므로(DC 필터) R23.2 (13.82, −41.93) 북쪽·J9 오른쪽 틈(x 11.7~13.1, 세로로 돌려 중심 y 약 −42.3; J9.3 패드 가장자리 x 11.35, R23 패드 x 13.42 사이)이나 다른 빈 자리를 쓴다. 옮긴 뒤 GND 비아 (10.3, −38.9)와 HP_DET 선을 다시 잇고 DRC를 돌린다.
- 보드를 안 고칠 경우의 우회: J4에는 하우징 대신 전선을 직접 납땜하거나, 3번 핀 쪽 하우징 밑을 깎는다.

## 고치면 좋은 것 (SHOULD)

### S1. DAC가 꺼져 있을 때 HP_DET이 HIGH로 뜰 수 있음 (미확인 위험)

- 회로: 미삽입 때 J8.4(TN)–J8.5(T)가 붙어 있고, HP_DET은 R23 4.7k → HP_L → R19 100 Ω → U6 OUTL(6번)을 통해서만 0 V로 당겨진다. HP_L에는 GND로 가는 저항이 없다(C19 2.2 nF뿐).
- PCM5102A는 BCK/LRCK가 약 1초 멈추면 자동으로 파워다운에 들어가 차지펌프를 끈다. 이때 OUTL이 0 V로 붙들려 있는지, 하이 임피던스인지 데이터시트에서 확인하지 못했다. 하이 임피던스라면 Pi 내부 풀업(약 50k)이 HP_DET을 HIGH로 올려 **재생이 멈춘 동안 "이어폰 삽입"으로 읽힌다**(부팅 직후, 채널 전환 사이, BT 출력 중).
- 대책(택일):
  - 보드: HP_L–GND에 **2.2 kΩ**(0603) 하나 추가 → DAC 상태와 무관하게 미삽입 = 3.3 × (4.7+2.2)/(50+6.9) ≈ 0.40 V(LOW). DAC 부하로도 문제없다. C19 옆에 자리가 필요하다.
  - 소프트웨어: 재생 중(I2S 클록이 도는 동안)에 읽은 값만 믿거나, 오디오 장치를 계속 열어 둔다. 보드를 그대로 두면 시제품에서 "재생 정지 상태의 GPIO23 전압"을 먼저 잰다.

### S2. JLC 조립 주문 때 정할 것

- **THT 부품**: J3~J8에 LCSC 번호가 들어 있어 BOM에 실린다. J8(잭)은 원통이 보드 위 변 밖으로 3.05 mm, J2는 1.0 mm, D2/D3 렌즈는 실물 기준 약 0.25 mm(Fab 그림은 0.10 mm) 나온다. 가장자리 밖으로 나오는 부품이 있으니 JLC가 공정용 테두리(edge rail)를 붙이도록 주문하고, **J8과 J1은 손납땜**을 권한다(J1은 LCSC 없음 → 자동으로 빠짐). J3~J7도 손납땜으로 빼면 Extended 셋업비가 줄어든다.
- **회전 확인**: 위치 파일은 JLC용 회전 보정이 들어가는 플러그인으로 뽑고, 조립 미리보기에서 1번 핀 점을 하나씩 본다 — U1(r−90), U2, U3(r180), U4(r90, SOT-563), U5(r90), U6(r−90), U7, Q1(r−90), Q2(r90), D1/D4 캐소드(D1 패드 1 = (49.0, −49.9) SYS 쪽, D4 패드 1 = (53.6, −43.25) VBUS 쪽), C8 +극(패드 1 = (31.8, −60.8)), J2 방향, D2/D3 렌즈.
- J9는 DNP·BOM·위치 파일 제외로 표시되어 있다(확인). JP1·H1~H5는 BOM 제외.

### S3. WSP8814(C148371) 핀 배치를 JLC 부품 페이지에서 한 번 더 볼 것

- 보드: 1·8 = `/FET_D`, 2·3 = `/B-`, 4 = `/OD`, 5 = `/OC`, 6·7 = GND (8205A/AO8814와 같은 배열).
- 이번 검토에서 Winsok 데이터시트 PDF를 열지 못해 직접 대조는 못 했다(사양서에는 확인했다고 적혀 있음). JLC 부품 페이지의 Pinout 그림으로 1분이면 확인된다. 회로가 좌우 대칭이라 S1/G1과 S2/G2가 서로 바뀌어도 동작은 같다 — 드레인이 1·8번이기만 하면 된다.

### S4. J8 고정 구멍과 보드 가장자리 사이 0.4 mm

- NPTH Ø1.2 두 개가 (11.0, −63.9), (21.0, −63.9), 보드 위 변은 y −64.9 → 구멍 가장자리에서 보드 끝까지 0.4 mm. 부품 치수(앞면에서 1.0 mm)에서 나오는 값이라 잭 앞면을 보드 변에 맞추는 한 피할 수 없다. JLC 규칙상 통과는 하지만 얇아서 깨질 수 있다. 신경 쓰이면 J8을 0.3~0.5 mm 안쪽으로 넣고 케이스 구멍 깊이를 그만큼 맞춘다.

### S5. 이전 검토에서 남긴 것 중 그대로인 것 (참고)

- TP4056 1 A 충전 때 발열(1.3~1.8 W) — EP 비아 12개로 늘었지만 열 조절로 충전 전류가 줄 수 있다. 시제품에서 온도 측정.
- Q1 AO3401A 약 60~70 mΩ(배터리 낮을 때), D1 SS34 동박 46 mm² — 시제품에서 온도 측정.
- I2S 직렬 저항 없음, CHG_DIS 160 mm — 시제품 관찰.

## 확인만 한 것 (검증 완료)

**도구 결과 (직접 실행)**
- ERC: 오류 0, 경고 1(U7 EP 핀 형식, 무해).
- DRC: 구리 오류 0, 연결 안 됨 1(+3V3 두 덩어리, 제외 등록됨), 회로도↔보드 불일치 0, 실크 경고 271(silk_overlap 199, edge 71, over_copper 1). `--refill-zones`로 다시 채워도 결과 같음 → 존 채우기가 최신 상태다.
- 프로젝트 DRC 설정에서 구리 관련 검사가 꺼져 있거나 낮춰진 것 없음. 규칙 파일은 JLC 2층 기준(선폭·간격 0.15, 비아 0.3/0.6, 가장자리 0.3).

**회로 (넷리스트 핀별 대조)**

## 사용자가 실물로 확인할 것

1. **배터리 플러그 극성**: 꽂기 전에 전선 +가 실크 "+"(J3 핀 1, x 47.5) 쪽인지 멀티미터로 확인. 역극성 보호가 없다.
2. **배터리를 처음 꽂은 뒤 전원이 안 들어오면** USB를 한 번 꽂는다(DW01A 계열은 첫 연결 뒤 충전기를 한 번 물려야 풀리는 경우가 있다).
3. **잭 원통 지름**(실물 PJ-307C)과 **LED 렌즈 돌출**(약 0.25 mm) → 케이스 구멍 치수.
4. **이어폰 좌/우**가 맞는지, 이어폰을 뺐을 때·꽂았을 때 스피커 전환이 되는지(재생 중 / 정지 중 둘 다).
5. **J4 듀폰 플러그**가 끝까지 들어가는지(M2를 안 고쳤다면 특히).
6. Pi의 micro-USB 전원 포트에는 전원을 꽂지 않는다(보드 5 V와 부딪침, 실크에 적혀 있음).
7. 충전 중 U1·D1·Q1 주변 온도, 큰 음량에서 5 V 레일 전압.
