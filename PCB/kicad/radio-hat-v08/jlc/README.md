# JLCPCB 제작·조립 파일 (radio-hat-v08)

생성: 2026-11-12, `kicad-cli`(KiCad 10.0.8)로 `radio-hat-v08.kicad_pcb`를 읽기만 해서 뽑음. 설계 파일은 수정하지 않았고, 구리 존은 저장된 채움 상태(전부 채워져 있음)를 그대로 썼다(다시 채우기 없음).
보드 크기: Edge.Cuts 기준 약 **63.5 x 70.0 mm** (케이스 메모의 63.48 x 69.98 mm와 같음).

## 파일 목록

| 파일 | 내용 |
|---|---|
| `radio-hat-v08_gerbers.zip` | **JLC 제작 주문에 올릴 파일.** 거버 9장(F/B Cu, F/B Mask, F/B Silkscreen, F/B Paste, Edge.Cuts, Protel 확장자) + 드릴 2개(PTH, NPTH). X2/넷리스트 속성 끔, 실크는 마스크 개구부 제외 |
| `gerbers/` | zip의 압축 푼 내용. 추가로 `.gbrjob`와 드릴 맵(`*-drl_map.gbr`)이 들어 있다(zip에는 안 넣음, 참고용) |
| `bom.csv` | **조립 주문용 BOM** (J3·J4~J7 제외, 사용자 손납땜). 열: Comment, Designator, Footprint, LCSC Part # (34행, 68개 부품) |
| `cpl.csv` | 기본 BOM과 짝인 부품 위치 파일 (Designator, Mid X, Mid Y, Layer, Rotation. 상면만, mm) |
| `rotation_check.md` | JLC 미리보기에서 회전·극성을 눈으로 확인할 부품 표. **D2/D3 극성 미확정 경고 포함** |

드릴/위치 좌표는 모두 같은 절대 원점(보드 파일 좌표, Y 위쪽이 +)을 쓴다. 거버와 드릴과 위치 파일이 서로 일관된다(드릴 원점 설정 안 함). 위치 파일 좌표는 모든 부품이 외곽선 안에 들어오는 것을 확인했다(X 10.9~62.6, Y -1.0~60.8; 보드 범위 X -0.1~63.6, Y -5.2~65.0). Y가 양수 위쪽 방향인 것은 JLC 표준이다.

## 어떤 BOM을 올릴까

- **업로드: `bom.csv` + `cpl.csv`.** (2026-11-12 결정) THT 부품 J3(배터리 XH, C157931)와 J4~J7 헤더는 사용자가 손납땜 → BOM/CPL에서 뺐고 헤더 포함 변형 파일은 지웠다. 손납땜 부품은 LCSC로 따로 주문(J3 C157931, J4 C492411, J5 C492416, J6 C492413, J7 C492410).
- 헤더 4개(J4 PWR_SW 3핀, J5 LCD 8핀, J6 ENC 5핀, J7 SPK 2핀)는 THT 조립이라 JLC 추가 비용이 든다(THT/Extended 셋업비). 직접 납땜할 거면 기본 BOM이 맞다. (헤더 포함 변형은 손납땜으로 정해 지웠다.)
- `final_review` S2의 권고도 같다: J8과 J1은 손납땜, J3~J7도 빼면 셋업비가 줄어든다.

## 제외한 부품과 이유

| 부품 | 이유 |
|---|---|
| J1 | Pi 40핀 헤더, 손납땜. LCSC 번호 없음 |
| J8 | 이어폰 잭 PJ-307C, 최종 검토 권고에 따라 손납땜. 원통이 보드 위쪽 변 밖으로 약 3 mm 나옴 |
| J9 | UART 디버그 3핀 패드, DNP |
| J10 | 선택 버튼 패드 2핀(GPIO4), DNP |

| JP1 | 앰프 이득 솔더 점퍼(BOM 제외 표시) |

보드 필드의 LCSC 번호와 `radio-hat-v08_bom.csv`의 번호는 일치함을 확인했다. **LCSC 번호가 없는 조립 대상 부품은 없다**(없는 것은 J1, J9, J10, H1~H5, JP1이고 전부 제외 대상).

## 주문 옵션 제안

- 층수 2, 두께 **1.6 mm**, 구리 1 oz, 소재 FR-4. 개수는 시제품 5장 정도.
- 표면처리: **ENIG 권장.** 이유: TSSOP-10(0.5 mm 피치), TQFN-16(0.5 mm), SOT-563 같은 미세 피치 부품이 있어 납 도금(HASL)보다 패드가 평평하고, 손납땜하는 J1/J8 패드도 깔끔하다. 비용이 아쉬우면 HASL 무연도 조립 가능한 수준이다.
- 마스크 색은 자유(실크 대비가 좋은 녹색/검정 무광 등).
- **조립 면: 상면(Top)만.** 하면 부품 없음.
- **공정용 테두리(edge rail / process edge) 추가 필수.** J8 원통이 약 3 mm, J2(USB-C)가 약 1 mm, D2/D3 렌즈가 약 0.25 mm 보드 밖으로 나온다(`v08_final_review_fable.md` S2). J2와 LED는 오른쪽(+X) 변 쪽이라 이 변에는 레일이 붙지 않는 쪽(위/아래 레일)으로 정하는 것이 안전해 보이고, J8은 손납땜이라 조립 중에는 문제가 되지 않는다. JLC 화면에서 레일 위치(방향)를 고르는 항목이 있으니 미리보기에서 부품이 레일과 겹치지 않는지 보고, 불확실하면 JLC 고객센터에 문의.
- 비아 최소 드릴 0.3 mm(JLC 기본 가능 범위), 가장자리 NPTH 구멍(0.65, 1.2, 2.7 mm) 포함.
- 주문 메모 예시(D2/D3): `D2/D3: side-view LED, lens must face the board edge (+X); cathode = pad 1 (upper pad). If lens direction and polarity conflict, please contact me before placing`

## 주문 전 확인 목록

1. 미리보기에서 `rotation_check.md`의 확인 항목을 하나씩(핀 1 점, 극성): U1~U7, Q1/Q2, D1/D4, C8, J2, **D2/D3**.
2. WSP8814(U3, C148371) 핀 1/8 = 드레인(JLC 부품 페이지), WSP8814와 FXL0420-1R0-MA1(L1, C53426685) 재고 확인.
3. 확장(Extended) 부품은 셋업비가 붙는다. 부품 단가와 재고는 주문 화면에서 확인.
4. 거버 뷰어(JLC 온라인)로 외곽선, 가장자리 구멍, 실크가 의도한 대로 올라왔는지 본다.

## 2026-11-12 JLC 미리보기에서 확인한 회전 보정 (cpl.csv에 반영됨)
JLC 라이브러리 기준 방향이 KiCad와 달라 미리보기에서 칩이 돌아가 보였다. `cpl.csv` Rotation을 고쳐 다시 올린 뒤 분홍 점(JLC 1번 핀)이 보드 실크 1번 표시와 일치함을 확인.
- −90°(화면 시계 방향 90°): U1, U2, U5, U6, U7 (270→180, 0→270, 90→0, 270→180, 0→270)
- 180°: Q1 (270→90), Q2 (90→270), U4 (90→270)
- 그대로 맞음: C8, D1, D4, D2/D3(위 패드 = 캐소드, JLC 표시 − 위/+ 아래), 수동부품.
- 확인 못함: U3 WSP8814 — JLC 3D 모델 없음. "Confirm Parts Placement" 로 JLC 엔지니어 확인에 맡김(보드 1번 핀 = 실크 삼각형 쪽, 오른쪽 아래).
- D2는 적색(Standard 전용) 대신 청색 XL-1606UBC C965865.
